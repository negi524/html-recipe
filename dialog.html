dialogサンプル

HTML 標準の <dialog> タグの挙動を確認するページ。

1. モーダルダイアログ（showModal）

showModal() で開くとページ全体が inert 状態になり、 背景に ::backdrop が表示される。ESC キーで閉じられる。

モーダルダイアログ

これはモーダルダイアログです。背景操作はブロックされます。

2. 非モーダルダイアログ（show）

show() で開くと背景は操作可能。::backdrop は表示されず、 ESC キーでも閉じない。

非モーダルダイアログ

背景を操作できます。

3. backdrop クリックで閉じる

::backdrop をクリックしたら閉じる挙動を JS で付与した例。 ダイアログ内側のクリックでは閉じない。

backdrop クリックで閉じるモーダル

ダイアログの外側（暗い部分）をクリックすると閉じます。

4. returnValue を受け取る

<button value="..."> を form method="dialog" 内で submit すると、 その value が dialog.returnValue に入る。
